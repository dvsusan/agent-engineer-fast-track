# 旅行行程建议

## 何时使用

当用户要规划旅行路线、挑选景点、安排酒店或比较行程节奏时使用本技能。

## 边界

本技能只提供行程组织建议，不处理财务报表、流水、会计科目或结余核对。涉及这些任务时应选择其他技能。
